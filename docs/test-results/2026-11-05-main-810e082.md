### 대표 실패 경로

`page-merge-seq`의 변환된 호출 스택에는 다음 경로가 나타났다.

```text
__do_fork
supplemental_page_table_copy
vm_claim_page
vm_do_claim_page
vm_get_frame
vm_evict_frame
vm_get_victim
pml4_is_accessed
pml4e_walk
```

`swap-anon`의 실패 호출 스택에는 `vm_try_handle_fault → vm_do_claim_page → vm_get_frame`이 나타났고, 출력에는 다음 메시지가 있었다.

```text
Page fault at 0x8: not present error reading page in kernel context.
Kernel PANIC at ../../userprog/exception.c:97 in kill():
Kernel bug - unexpected interrupt in kernel
```

이는 실패 위치의 관측 근거다. 각 테스트의 근본 원인을 모두 수정·검증했다는 의미는 아니다. 코드 검토에서는 교체 대상의 페이지 테이블 수명, page/frame 연결 해제 순서, 스왑 슬롯과 자원 정리 경로를 점검 대상으로 확인했다.

COW는 `vm_handle_wp()`가 비어 있는 현재 구현 상태와 함께 기록한다.

개발 컨테이너에서 저장소 루트를 기준으로 실행한다.

```bash

```
